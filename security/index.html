Website information

Security

This portfolio is a static website. It does not expose visitor logins, password storage, payment processing or user-submitted public APIs.

Protective measures

The deployment uses HTTPS, browser security headers and Vercel managed bot protection. GitHub Actions publishes only public repository metadata and validated public LinkedIn publication references. The workflow token is provided by GitHub Actions and is not embedded in browser code. Private repository data is not published.

Some advanced Vercel firewall rules and BotID features are not available on the current hosting plan. No website can be described as immune to attacks.
